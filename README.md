# rightbite-tasting-bot

LINE bot ของ Right Bite Factory — ระบบชิมเนยถั่ว และแจ้งเตือนเปิดเครื่องลดความชื้น

---

## 💨 แจ้งเตือนเปิดเครื่องลดความชื้น (ผลิตพิสตาชิโอ้ข้ามคืน)

ทุกครั้งที่มีการผลิตพิสตาชิโอ้ข้ามคืน: **ทุกคนต้องกดรับทราบ** และ **คนที่เปิดเครื่องต้องลงชื่อ**
ถ้ายังไม่ครบ ระบบจะเตือนซ้ำไปเรื่อย ๆ

### หลักสำคัญ: ยึด "คืนที่เริ่มเดินเครื่องจริง" ไม่ใช่ "วันที่ในแผน"

บางครั้งแผนผลิตเขียนว่าผลิต **พรุ่งนี้** แต่หน้างานเริ่มผลิตข้ามคืนตั้งแต่ **คืนนี้**
ถ้าระบบเตือนตามวันที่ในแผน จะเตือนช้าไป 1 วัน — ระบบนี้จึงถามวัน-เวลาที่เริ่มเดินเครื่องจริง
แล้วแสดงวันที่เต็ม + นับถอยหลัง (เช่น `อ. 3 พ.ย. 20:00 (อีก 6 ชม.)`) ให้ทุกคนเห็นและทักท้วงได้ทันที

### ไทม์ไลน์ 1 รอบ

| เวลา | ระบบทำอะไร |
|---|---|
| ตอนแจ้งรอบ | ส่งแจ้งล่วงหน้าให้ **ทุกคน** ที่ลงทะเบียนกับบอท → ทุกคนต้องกด "รับทราบ" |
| ยังไม่กดรับทราบ | เตือนเฉพาะคนนั้นซ้ำทุก **30 นาที** |
| **เริ่มผลิต − 60 นาที** | 🚨 "ถึงเวลาเปิดเครื่องลดความชื้นแล้ว" ส่งทุกคน |
| ยังไม่มีคนลงชื่อเปิดเครื่อง | เตือน **ทุกคน** ซ้ำทุก **15 นาที** (เลยเวลาเริ่มผลิต → ข้อความด่วนขึ้น) |
| มีคนลงชื่อเปิดเครื่อง | แจ้งทุกคนว่าใครเปิดเมื่อไหร่ → หยุดเตือนด่วน |
| เปิดเครื่องแล้ว + รับทราบครบ | ปิดรอบ ✅ แจ้งคนที่แจ้งรอบ |
| เริ่มผลิต + 16 ชม. แต่ยังไม่ครบ | ปิดรอบอัตโนมัติ แจ้งฝ่ายผลิตว่าใครขาด / ไม่มีคนลงชื่อเปิดเครื่อง |

- แจ้งช้า (เลยเวลาเปิดเครื่องแล้ว หรือเริ่มผลิตไปแล้วไม่เกิน 3 ชม.) → เตือนด่วนทันที
- คนที่ลงทะเบียนกับบอทระหว่างรอบ จะได้รับแจ้งเตือนด้วย

### คำสั่ง (พิมพ์ในแชตบอท)

| พิมพ์ | ทำอะไร |
|---|---|
| `ข้ามคืน` | แจ้งรอบผลิตข้ามคืน — มีปุ่มให้เลือกคืน แล้วเลือกเวลาเริ่ม |
| `ข้ามคืน คืนนี้ 20:00` | แจ้งรอบแบบพิมพ์เอง (ใช้ได้: `คืนนี้` `พรุ่งนี้` `มะรืน` `5/11`) |
| `ข้ามคืน 5/11 ตี2` | ตี1–ตี5 / เที่ยงคืน = เช้ามืดของวันถัดไป (ในตัวอย่างนี้คือ 6/11 02:00) |
| `ข้ามคืน ตอนนี้` | เริ่มผลิตเลย → เตือนเปิดเครื่องด่วนทันที |
| `รับทราบ` | กดรับทราบ (หรือกดปุ่ม ✅ รับทราบ) |
| `เปิดเครื่องแล้ว` | ลงชื่อว่าเป็นคนเปิดเครื่อง (มีให้กดยืนยันอีกครั้ง) |
| `ลดความชื้น` | ดูสถานะ: เครื่องเปิดหรือยัง ใครรับทราบแล้ว ใครยังไม่รับทราบ |
| `ยกเลิกข้ามคืน` | ยกเลิกรอบ (เฉพาะฝ่ายผลิตหรือคนที่แจ้งรอบ) — ใช้ตอนแผนเปลี่ยนหรือแจ้งผิดวัน |

การลงชื่อเปิดเครื่องผูกกับบัญชี LINE ที่ลงทะเบียนชื่อไว้ จึงรู้แน่ว่าใครเปิด

### บันทึก

ทุกรอบบันทึกในชีต **`ลดความชื้น`** (สร้างให้อัตโนมัติ): เวลาเริ่มผลิต, คนเปิดเครื่อง + เวลา,
ใครรับทราบเมื่อไหร่, ใครยังไม่รับทราบ, จำนวนรอบที่เตือนด่วน
คอลัมน์สุดท้าย "ข้อมูลระบบ" ใช้กู้สถานะเมื่อเซิร์ฟเวอร์รีสตาร์ท — **ห้ามแก้**

### ปรับค่าได้ที่ `dehumidifier.js` → `DEFAULTS`

`leadMin` (เปิดก่อนเริ่มผลิตกี่นาที, 60) · `urgentEveryMin` (15) · `ackEveryMin` (30) · `autoCloseHours` (16)
